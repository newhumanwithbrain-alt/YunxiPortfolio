# Taro Yunxi Portfolio

A clean and minimalist portfolio website with a soft cloud blue theme.

## Features

- 🎨 Minimalist design with cloud blue color scheme
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Smooth scrolling and fade-in animations
- 🎯 Simple and easy to customize
- 📄 Single page application

## Sections

- **Home** - Hero section with introduction
- **About** - Brief bio and skills
- **Contact** - Links to connect

## Color Palette

- Primary Light: `#e8f4f8`
- Primary Blue: `#b8dde8`
- Primary Dark: `#7eb3d4`
- Accent Blue: `#5a9fd4`

## How to Use

1. Clone this repository
2. Open `index.html` in your browser
3. Customize the content to match your information
4. Deploy to GitHub Pages or any hosting service

## Customization

### Edit Your Information
- Change name and title in `index.html`
- Update bio and skills in the About section
- Add your social media links in the Contact section

### Change Colors
Edit the color variables in `style.css`:
```css
:root {
    --primary-light: #e8f4f8;
    --primary-blue: #b8dde8;
    --primary-dark: #7eb3d4;
    --accent-blue: #5a9fd4;
}
```

## Deploy to GitHub Pages

1. Go to repository Settings
2. Find "Pages" section
3. Set source to "main" branch
4. Your site will be live at `https://yourusername.github.io/YunxiPortfolio`
